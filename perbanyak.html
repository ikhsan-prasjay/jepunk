Alat Perbanyak Data (Menjadi 500)

Karena skrip sistem merusak tulisan Jepang (masalah encoding Windows), kita gunakan browser untuk memperbanyak datanya.

Langkah-langkah:

  1. Pastikan Anda sudah menekan Ctrl + Z di file data.js pada editor Anda sampai teks Jepangnya kembali normal.
  2. WAJIB: Tekan Ctrl + S (Save) agar file data.js yang benar tersimpan di disk.
  3. Setelah disimpan,
  4. Lalu klik tombol di bawah untuk mendownload data_baru.js yang sudah berisi 500 kata.
  5. Ganti isi data.js Anda dengan isi dari data_baru.js yang didownload.
